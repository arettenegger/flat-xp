Verwaltung

Bitte mit dem GitHub-Zugangsschlüssel anmelden.

Wie bekomme ich einen Schlüssel?
  1. Auf github.com anmelden → Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name z. B. „Flat-XP Verwaltung“, Ablaufdatum wählen.
  3. Repository access: Only select repositories → flat-xp.
  4. Permissions → Repository: Contents: Read and write, Actions: Read-only.
  5. Token erzeugen, kopieren und hier einfügen.
